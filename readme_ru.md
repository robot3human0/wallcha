# Wallpaper Changer 2.0

## Описание

Небольшой демон на C++ для рабочих окружений **XFCE**, автоматически изменяющий обои рабочего стола через заданный интервал.
Программа сканирует каталог (включая вложенные папки), собирает список поддерживаемых изображений и циклически меняет фон рабочего стола.

> Для установки обоев используется скрипт xfce4-set-wallpaper из набора инструментов xapp (Linux Mint). Это позволяет не работать напрямую с xfconf-query.

### Поддерживаемые форматы изображений
* jpg / jpeg
* png
* bmp

### Зависимости
xfce4-set-wallpaper<br>
Источник:<br>
https://github.com/linuxmint/xapp/blob/master/scripts/xfce4-set-wallpaper Или можно взять копию из директории **resources**.

> Скрипт необходимо установить вручную.

## Использование
```
wallcha -d <путь/до/каталога> -c <минуты>
```

## Опции
```
-d, --directory   Путь к каталогу с обоями.
-c, --count       Интервал смены обоев в минутах.
                  Если параметр не указан, используется значение по умолчанию — 30 минут.
-h, --help        Показать справку.
-v, --version     Показать версию программы.
```

## Примеры
Запуск с каталогом и пользовательским интервалом:
```
wallcha -d ~/Pictures/wallpapers -c 10
```

Запуск с интервалом по умолчанию (30 минут):
```
wallcha -d ~/Pictures/wallpapers
```

### Поведение
* Рекурсивно сканирует указанный каталог и подкаталоги.
* Собирает список всех поддерживаемых изображений.
* Проверяет корректность аргументов и существование каталога.
* Порождает фоновый процесс (демон).
* Циклически меняет обои в указанном порядке.
* Не обновляет список файлов во время работы (планируется в будущих версиях).

### Примечания
* Максимальный интервал: 1440 минут (24 часа).
* Минимальный интервал: 1 минута (0 означает значение по умолчанию).
* Список найденных изображений хранится в памяти на протяжении всей работы.
* Требуется рабочее окружение XFCE.
